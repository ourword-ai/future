HBAI-Ltd/Toonflow-app

HBAI-Ltd/Toonflow-app —— 开源一站式 AI 短剧创作工具,把小说/剧本快速转成动画短剧(AI 编剧、智能分镜、角色与视频生成),跨平台桌面轻量部署。

更新于 2026-07-27 · 来源 https://github.com/HBAI-Ltd/Toonflow-app · 英文版

Q：这条到底是什么？

开源桌面应用，把小说或剧本一路带到动画短剧：AI 编剧 → 分镜表与分镜图 → 角色与图像生成 → 视频合成，全程用你自己的模型 key。跨平台、部署轻量，几周内 1.3 万星。

Q：谁在用？他拿到什么成品？

它本来就是创作者产品：买家是小型短剧工作室，不是开发者。

Q：他为什么非要用不可？

写网文的人不是剪辑师。从写完一章到做出一集能看的片子，中间横着一条他们根本没办法自己走的生产线。

Q：今天缺的到底是什么？

它击中了真痛点但解得不完美，而且恰恰断在最关键的一环：剧本 → 分镜表 → 提示词会被截断，还会「成功写入」却一条都看不到，创作者只能盯着 token 上限反复重跑。此外它实际只服务中文用户——一个英文用户连登录弹窗都过不去。

Q：这一刀切在哪里？

别做流水线。做那个一直坏、又几乎不花钱的环节：一个绝不截断的「小说 → 分镜表」转换器（分块、可续跑、结构校验），并把每个镜头的干净提示词导出到可灵 / 即梦 / Runway——按剧本卖给那些本来就在别处为生成付费的短剧工作室。

Q：它最锋利的地方在哪？

它的终点是一集能播的成片，而不是一堆素材——剧本、分镜、角色、视频，在桌面上一次走完。

Q：什么会杀死它？

这是板上最吃资本的一条：每一秒成片都在烧模型钱，而可灵 / 即梦 / 海螺 同时握着模型和分发——字节把整条流水线塞进剪映，一夜之间就能把独立开发者挤出价格。1.3 万星背后只有 9 位贡献者，bus factor 是 1。整条流水线正是标准里排除的「烧钱抢速度」赛道，对你开放的只有其中很窄、纯文本的一刀。

Q：谁付钱，付的是什么？

已经在按秒为生成付费的短剧工作室与小说 IP 方——他们愿意为「不再浪费这些秒」的那一步买单：一张能撑到最后一格的分镜表。

Q：最大的风险是什么？

剪映或可灵原生集成分镜生成；1.3 万星的仓库只靠 9 位贡献者撑着。

Q：真人原话是怎么说的？

以下原声逐字摘自公开来源，未经改写： “每次生成分镜表时，一直被截断，重新生成又被截断，使用的是DeepSeek V4 Pro” — GitHub issue

Q：要做多久？

两周左右的工作量
