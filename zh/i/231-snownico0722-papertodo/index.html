体验 PaperTodo 的极简桌面便签，享受无杂乱工作空间

体验 PaperTodo 的极简桌面便签，享受无杂乱工作空间——已有 1,282 个星标！

更新于 2026-07-28 · 来源 https://github.com/snownico0722/PaperTodo · 英文版

Q：这条到底是什么？

PaperTodo 是一款极简的 Windows 桌面便签工具，允许用户在桌面上直接创建独立的便签和待办事项，而无需管理界面。它支持 Markdown，增强了记笔记的体验。

Q：谁在用？他拿到什么成品？

用的人是那种把便利贴粘在显示器边框上的 Windows 用户。他拿到的就是同一张便利贴，只不过在屏幕上——安静、一直在、不用注册、不同步、没有连续打卡、什么都不催他。它 issue 区里提需求的是双屏办公的普通人（想把便签拖到另一块屏上），不是开发者在提 feature request。

Q：他为什么非要用不可？

选择 PaperTodo，因其简单性和对即时可用性的关注，与其他需要复杂设置和账号管理的记事应用不同。

Q：今天缺的到底是什么？

缺口不是「只有极客能用」，恰恰相反：它已经足够简单，而它自己的 issue 区里是一群双屏普通用户，抱怨没法把便签挪到另一块屏上。是主流笔记应用集体走去了另一边——账号、同步、工作区——把桌面本身空了出来。

Q：这一刀切在哪里？

不卖那张纸，卖纸后来去哪了。桌面便签三十年没做过的一件事是「记得」——三个月前写在一块你已经不用的显示器上的那张，就这么没了。同样安静的纸，加上「这台机器上我写过的所有东西，能搜，永不上传」。冷启动第一步：中文＝小红书「桌面便签 推荐」「电脑便签 不打扰」标签下的评论区；英文＝r/Windows 与 r/productivity 里求「不要账号的便签」的帖子。

Q：它最锋利的地方在哪？

每张便签作为独立窗口操作，使用户能够快速访问和互动，而无需多余的点击或干扰。

Q：什么会杀死它？

这是一个免费小工具，而这个品类三十年来是免费赢：Windows 自带便笺，没有人为一张便利贴付过钱。issue 区的诉求也是没有边界的打磨（分屏摆放、右键菜单、胶囊行为），小工具就是这样悄悄长成大软件、却始终没长成生意。

Q：谁付钱，付的是什么？

寻求无干扰记笔记体验的个人用户为能够即时记录想法和任务而付费，无需传统应用的复杂性。

Q：最大的风险是什么？

微软 OneNote 或 Evernote 等成熟的生产力工具主导市场，因其丰富的功能集，用户采用面临挑战。

Q：真人原话是怎么说的？

以下原声逐字摘自公开来源，未经改写： “…希望添加右键主胶囊能够有像右键任务托盘中软件图标一样的功能列表， 希望右键胶囊能够添加一个发送到其他屏幕的功能，可以选择发送到不同的显示屏，我有两个屏幕，如果要设置到另一个屏幕有点太麻烦了，希望能便捷一些。，如果不行的话是否能在设置里设置胶囊显示的主屏幕。” — github
