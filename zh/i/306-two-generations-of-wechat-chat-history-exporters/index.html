两代微信聊天记录导出工具加起来约 5.5 万星

两代微信聊天记录导出工具加起来约 5.5 万星，issue 区里有人直接说「有偿也行」——但它们全都停在「导出＋一次性年度报告」，没有一个把这堆语料变成能一直问下去的档案。

更新于 2026-08-03 · 来源 https://github.com/hicccc77/WeFlow · 英文版

Q：这条到底是什么？

WeFlow、WeChatMsg 把用户自己电脑上的微信数据库解密导出；robbin/wechat-exporter（2026-07-28 建仓）把「重签名取密钥→解密成明文 SQLite→注册成 MCP 直接问」整条链压成一个 Claude Code / Codex 技能，一条命令跑完。

Q：谁在用？他拿到什么成品？

用的人是一个成年子女，自己的笔记本里躺着十年的家庭群聊和父母的语音条，全是加密的。他拿到的是：把其中一段对话印成一本可以放在书架上的册子，以及可以对着这段对话问一句「妈那年到底是哪天住的院」——而且全过程一个字节都不出这台电脑。导出只是管道，那本册子才是产品。

Q：他为什么非要用不可？

对很多人来说，微信是这辈子最密的一份记录：十年家庭群、爸妈的语音、一段关系从第一条消息开始。它就在本机，加密、跨年搜不动，而且换手机就常常整段消失。

Q：今天缺的到底是什么？

现有的要么是只有开发者跑得动的命令行/技能，要么是一次性的年度报告海报——没人做「导完之后能一直问」的那一层。

Q：这一刀切在哪里？

不要在导出上竞争，从导出之后切进去，只做一件窄事：挑一段家人的对话，本地问答＋印成一本纪念册。冷启动（中文）：去 WeFlow / WeChatMsg 的 issue 区和 fork 名单，私信那些在喊求 Mac 版、求没过期的安装包的人，再去小红书搜「微信聊天记录 导出」的求助帖评论区。冷启动（英文）：r/DataHoarder 与 r/China_irl 搜 WeChat export。

Q：什么会杀死它？

WeChatMsg 从 2023 年做到今天 41.9k 星，随时可能有人正规化补位；客户端一更新解密就失效（WeFlow 用户此刻就卡在过期版本上），平台也没有让它稳定的动机。

Q：谁付钱，付的是什么？

一次性买断的桌面应用，纪念册打印作为增值——买家和已经花钱找店家数字化家庭影像的是同一批人。

Q：最大的风险是什么？

解密随客户端版本失效，且虽然是用户自己的数据，仍处在平台条款的灰色地带；产品必须严格本地、只处理本人数据、不留云端副本。
