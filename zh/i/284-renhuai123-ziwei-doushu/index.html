紫微斗数开源排盘引擎（倪海厦《天纪》体系）

紫微斗数开源排盘引擎（倪海厦《天纪》体系）：完整排盘算法 + 四化系统 + 格局知识库 + 古籍原文结构化数据。

更新于 2026-07-29 · 来源 https://github.com/Renhuai123/ziwei-doushu · 英文版

Q：这条到底是什么？

把玄学领域变成机器可读的基础设施：完整排盘算法、四化系统、格局知识库和古籍原文数据，AI 产品可以直接查询调用。

Q：谁在用？他拿到什么成品？

用的人是自己对紫微斗数好奇、但看不懂排盘的人。他拿到的是一张排好的盘，外加每一个格局在讲什么的人话解释。

Q：他为什么非要用不可？

做 AI 测算 / 陪伴类产品时，不必自己啃古籍手搓排盘逻辑，直接接一个算法和数据都齐的引擎。

Q：今天缺的到底是什么？

痛点击中了，但在离人一层的地方停住了：3317 星、736 fork——fork 超过星的五分之一，在这块板上算行为证据——说明有人在自己搭；但现在存在的是排盘引擎，不是一个人能开口问的东西。用人话讲出来的那份解读，还是缺的。

Q：这一刀切在哪里？

别再做一个测算 app，做那层诚实的翻译。盘进去，人话出来，每一句都脚注到它出自哪一段古籍原文，并且明写这是文化文本、不是建议。别人没有的资产是结构化的原文——就靠出处站住，而这恰好是免费 app 拿不出来的东西。冷启动（中文）：小红书与豆瓣的紫微斗数小组，人们贴一张盘的截图问这是什么意思；冷启动（英文）：r/ChineseAstrology 与 r/asianastrology，同样的盘贴出来，英文世界根本没有解读。

Q：它最锋利的地方在哪？

护城河在语料不在代码：数字化古籍 + 规则引擎，而竞品大多只是拿 LLM 凭感觉生成。

Q：什么会杀死它？

这个品类在会付钱的那个市场里政策脆弱：国内应用商店和支付渠道对测算变现有限制，所以分发就是全部问题，而算法来自公开古籍，任何在位者都能重新推一遍。两位贡献者，对一个必须准确的知识库来说也太薄。这里还得自限——这是民俗文本不是建议，一旦滑向替人决定要不要接那份工作，就是责任。

Q：谁付钱，付的是什么？

中文命理是被验证过的付费市场（测算 App、知识付费、直播看盘）。最优路径不是做 C 端，而是当排盘 API / 授权后端卖给 AI 测算和陪伴类产品。

Q：最大的风险是什么？

只有 2 个贡献者，且品类政策脆弱：国内应用商店和支付渠道对命理变现多有限制，大厂测算 App 也能从同样的公开古籍重新推导算法。
