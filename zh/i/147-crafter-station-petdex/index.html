crafter-station/petdex

crafter-station/petdex —— 给 Codex、Claude Code、OpenCode、Gemini CLI 的动画宠物公共画廊。

更新于 2026-07-27 · 来源 https://github.com/crafter-station/petdex · 英文版

Q：这条到底是什么？

一个公开的动画像素宠物画廊，宠物住在 coding agent 的终端里：3686 星、167 fork，还有一个投稿队列，人们把自己手画的小生物传上去——其中源源不断有中文投稿，还有一位版权方来要求下架。

Q：他为什么非要用不可？

想让屏幕上住一只小东西的人：桌宠受众是中学生和上班族，不是程序员。他拿到的是一只自己画出来、会动的伙伴。

Q：今天缺的到底是什么？

宠物被关在终端里，只有程序员看得见。这件事真正更老也更大的受众——桌面宠物、Shimeji 那一脉——待在普通人的电脑和手机上，而他们从 2010 年代起就只能用一批停止维护的免费软件。

Q：这一刀切在哪里？

拿走流水线，扔掉终端。真正有意思的是：普通人正在成规模地画并投稿像素小生物。产品是「画一只，就得到一个会对你此刻在干什么做出反应的动画桌宠」——放在 Windows 和 macOS 上，桌宠受众本来就在那里。冷启动（中文）：小红书、B站搜「桌宠 自制」，以及 Shimeji 教程下的评论区，挤满做到一半放弃的人；冷启动（英文）：r/Shimeji 与 r/desktops。

Q：它最锋利的地方在哪？

把一张手画角色变成干净的循环精灵图，过去是画师一下午的活。图生精灵把它压成一次上传——这也是一个公开投稿队列能以这个速度被业余画作塞满的唯一原因。

Q：什么会杀死它？

半衰期很短的新鲜感，且没有护城河：梗会过去，握着终端的那一方会自己发一个，而画廊真正的资产——用户投稿的画——在赚到第一分钱之前就已经引来了 IP 下架请求（issue #651）。桌宠还免费了十五年，为它收费是件没被验证过的事。

Q：谁付钱，付的是什么？

除了也许卖点装饰包,没有真正的收入路径;是个讨喜的业余项目,不是公司。

Q：最大的风险是什么？

新奇无护城河、无留存;梗一过就凉,平台也能自己加。

Q：真人原话是怎么说的？

以下原声逐字摘自公开来源，未经改写： “这两个条目属于同一公开品牌 IP 的历史提交，当前不再属于授权发布集” — github-issue
