微软放出一个实验性桌面应用：你在屏幕上把一件事做一遍给它看

微软放出一个实验性桌面应用：你在屏幕上把一件事做一遍给它看，它就把这段过程还原成「意图＋有序步骤」，再生成一个可复用的 agent 技能——四天 835 星、90 个 fork。

更新于 2026-08-03 · 来源 https://github.com/microsoft/skill-recorder · 英文版

Q：这条到底是什么？

录下你的一段屏幕操作（可以边做边讲），交给 GitHub Copilot CLI 还原成意图和有序步骤，最后输出一个可复用的 Skill 或 Automation。

Q：谁在用？他拿到什么成品？

现在还没有人——这正是本条的价值。它要服务的人，是每个月都要在电脑上做一次十分钟琐事的普通人：下载对账单、改个名、放进对应文件夹；把同一张表再填一遍；把同样三个附件归档。这些事他既写不出脚本，也说不清楚到底怎么做——但他永远能亲手做一遍。他拿到的是：下个月这件事已经做完了，而那段录屏一步也没离开过他的电脑。

Q：他为什么非要用不可？

普通人每个月都要点一遍的那些重复活儿，恰恰是他们既写不出脚本、也说不清楚给 AI 听的——但他们随时能做一遍。

Q：今天缺的到底是什么？

它绑死在 Copilot CLI / Microsoft Scout / Copilot Studio 上，以 Electron 源码方式安装，面向的是企业流程作者。普通人那个版本——「做一遍给它看，以后它替你做」，不用配置任何东西——不存在，中文桌面这边更是完全空白。

Q：这一刀切在哪里？

这里只当能力信号，不当生意：机会在普通人那一侧——挑一件家里每月重复的窄活，用示范教会它，全程本地跑，屏幕录像一帧都不出这台机器。冷启动（中文）：小红书、B 站「办公自动化」「重复劳动」教程下的评论区，那里的人会把自己最烦的那套月度流程一条条说出来。冷启动（英文）：r/Automate 与 r/productivity 搜 automate this thing I do every month。

Q：什么会杀死它？

微软亲自占着这个位置，分发能力摆在那；而且演示本身是一份有损的说明书，维护者自己的 issue 里就写了：录漏一步，生成的技能就是坏的。fork 只有星数的 11%，目前还是开发者好奇，不算被验证的需求。

Q：谁付钱，付的是什么？

就它现在这个形态不是生意；普通人版本会是一次性买断的本地桌面应用。

Q：最大的风险是什么？

屏幕录像是最敏感的一类采集，不做到全程本地就卖不出去。

Q：要做多久？

不建议做，只作为能力信号存档
