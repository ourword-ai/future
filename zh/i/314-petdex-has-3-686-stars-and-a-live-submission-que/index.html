petdex 3686 星，还有一个活着的投稿队列，里面全是手画的像…

petdex 3686 星，还有一个活着的投稿队列，里面全是手画的像素宠物——包括源源不断的中文投稿，和一封版权方的下架函。但这些宠物只能在 coding agent 的终端里被看见。而它借来的那一脉受众——桌宠——自 Shimeji 之后再没有新东西。

更新于 2026-08-04 · 来源 https://github.com/crafter-station/petdex · 英文版

Q：这条到底是什么？

petdex 是给 Codex / Claude Code / OpenCode / Gemini CLI 用的公开动画像素宠物画廊：传一张精灵表，它就变成住在开发者终端里的一只小生物。投稿流水线、审核队列、版权纠纷，全都是真的在跑的。

Q：他为什么非要用不可？

桌面伴侣这一脉（Shimeji、桌宠）靠着一批停止维护的免费软件，养住了十年的非技术受众。没人做过一个现代的，而现在，孩子的一张画就能变成那只精灵。

Q：今天缺的到底是什么？

只有极客看得见。能力、画的流水线、受众三样都在，但分在三个地方：宠物住在终端里；想要屏幕上有个伴的人在普通的 Windows 和 macOS 上；而最新的那件事——一张手画的图直接生成整套动画精灵表——两边都没接上。

Q：这一刀切在哪里？

拿走流水线，扔掉终端，并且把输入从精灵表换成一张画。孩子的一张涂鸦拍进去，出来一个动画伴儿，住在 Windows 和 macOS 上，会对屏幕上正在发生的事做反应——你打字时它趴着，一开视频它抬头。按纪念品卖，不按工具卖：你家孩子画的那只，活在你的桌面上，还能导成一套贴纸。冷启动（中文）：小红书、B站搜「桌宠 自制」以及 Shimeji 教程下的评论区，挤满做到一半放弃的人；冷启动（英文）：r/Shimeji 与 r/desktops。

Q：它最锋利的地方在哪？

「画 → 会动的伴儿」这条流水线，已经被一群陌生人免费替你验证过了——缺的只是它该住进去的那扇窗。

Q：什么会杀死它？

桌宠已经免费了十五年，为它收费是件没被验证过的事，天花板可能干脆就是零。它还是个半衰期很短的新鲜感：梗会过去，握着桌面的那一方可以自己发一个；而 petdex 自己的 issue 区已经显示出用户投稿画廊的真实成本——#651 是版权方要求撤下两只宠物，这只是第一封。

Q：谁付钱，付的是什么？

一个家长，或者任何想让屏幕上有个伴的人——按只买断，定价像买一张画，不是订阅。

Q：最大的风险是什么？

这里还没有一条经过验证的一手抱怨，只有行为：人们在投稿。如果桌宠受众只是怀旧而不掏钱，整件事就是一个可爱的零。

Q：真人原话是怎么说的？

以下原声逐字摘自公开来源，未经改写： “这两个条目属于同一公开品牌 IP 的历史提交，当前不再属于授权发布集” — github-issue

Q：要做多久？

两周左右的工作量
